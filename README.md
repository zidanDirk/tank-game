# TANK / 1990 — 最后一道防线

Three.js 3D 俯视角「坦克大战」核心玩法原型。全部模型由程序化几何体组装，没有图片、模型下载或付费服务依赖。

战役模式包含 3 个连续关卡，通关后保留分数进入下一关，失败只重试当前关。第 2 关起解锁**经典道具系统**，收集道具可让玩家坦克升级、获得护盾、冻结敌人或加固基地。

**无尽模式**基于每日种子生成程序化地图，难度随波次递增，每 5 波出现可击击的巨型 Boss，本地排行榜记录前 10 名分数。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://localhost:5173），在 Ready 面板选择「战役模式」或「无尽模式」后点击「开始战役 ↗」。

```bash
npm test            # 碰撞、地图、道具和核心规则测试
npm run test:levels # 浏览器中的三关推进、难度和最终胜利回归
npm run test:browser # Playwright 端到端冒烟 + 截图
npm run build       # 输出 dist/
npm run preview
```

Vite 使用相对 base，可把 dist/ 部署到静态站点子目录。需支持 WebGL 2 的现代浏览器；不能通过双击 file:// 打开模块源码。

## 操作与规则

- WASD / 方向键：四向行进，90° 转向，转向时平滑对齐网格中心。
- 空格 / 鼠标左键：按住连续射击。
- 鼠标移动：炮塔独立瞄准；再次按方向键恢复朝移动方向射击。
- P / Esc：暂停或继续。R：立即重开。手机有方向键及射击按钮。
- 三条生命，每次入场有三秒保护。三关分别有 12、15、18 辆敌军；第 1、2 关清场后进入下一关，第 3 关清场才获胜。基地被任意炮弹击中，或生命耗尽则失败。
- 砖墙每个格子一击摧毁；钢墙吸收普通炮弹，玩家坦克升级到 4 级后可击破钢墙；水面允许炮弹经过，但坦克不能通过。
- 两颗炮弹碰撞相互抵消（不区分阵营）。己方坦克不挡己方炮弹，但基地会受到双方炮弹伤害。
- 轻型：1 HP，快速移动，100 分。重型：3 HP，低速，300 分。速射：1 HP，更短射击间隔，200 分。装甲：6 HP，双发，400 分。Boss：12 HP，三发，1500 分。
- 普通敌人随机每 1.5–3 秒射击，速射型 0.7–1.05 秒。AI 在巡逻中概率偏向基地或玩家，碰壁选择可行方向；第 2、3 关会进一步缩短间隔并提高移动速度。

## 道具系统（第 2、3 关与无尽模式）

击杀敌人有 22%（无尽模式 28%）概率掉落道具，道具自动飘向地图中心，6 秒内未被拾取则消失。玩家接触即生效。

| 道具 | 效果 | 持续 |
| --- | --- | --- |
| ★ Star | 玩家坦克升级（最高 4 级） | 瞬时 |
| 🪖 Helmet | 临时护盾，吸收一次伤害 | 10 秒 |
| ⏱ Clock | 全场敌人冻结（蓝色染色） | 7 秒 |
| 💣 Bomb | 屏幕内所有敌人立即受一击 | 瞬时 |
| 🚜 Tank | +1 额外生命（上限 5） | 瞬时 |
| 🧱 Shovel | 基地周围临时变为钢墙 | 15 秒 |

坦克升级曲线（`PLAYER_LEVELS`）：

| 等级 | 速度 | 冷却 | 多发 | 破钢墙 |
| --- | --- | --- | --- | --- |
| Lv1 | 4.10 | 0.30s | ×1 | ✗ |
| Lv2 | 4.40 | 0.22s | ×1 | ✗ |
| Lv3 | 4.70 | 0.22s | ×2 | ✗ |
| Lv4 | 5.00 | 0.18s | ×2 | ✓ |

## 局内战地改装

战役模式通过第 1、2 关后，以及无尽模式每完成 3 波后，会暂停战斗并随机提供三项改装。选择立即生效，并持续到本次战役或无尽挑战结束；失败重试当前关会保留构筑，开启新战役或重新挑战无尽模式会清空。

| 改装 | 单层效果 | 上限 |
| --- | --- | --- |
| 履带超频 | 移动速度 +10% | 3 |
| 自动装填 | 射击冷却 -12% | 3 |
| 高速弹 | 炮弹速度 +15% | 3 |
| 穿甲弹 | 炮弹伤害 +1 | 2 |
| 战场回收 | 道具掉率 +5% | 3 |
| 反应装甲 | 每次出生抵挡 1 次伤害 | 2 |

改装选择使用当前局的种子随机数，候选项不会重复，也不会继续出现已经叠满的改装。当前构筑显示在战场左上角，调试快照通过 `runUpgrades` 和 `upgradeChoices` 暴露状态。

## 无尽模式

- 每波从 4 套预设（六道走廊 / 钢墙迷宫 / 水域阻击 / 围城死斗）抽取，旋转 + 镜像后落地；基地与外墙始终保留。
- 敌人上限 `4 + floor(wave/3)`；射速乘子 `1 / (1 + wave * 0.04)`；移动速度每波 +6%。
- 第 5 波解锁装甲兵种（双发 / 6 HP），第 10、15、… 波出现 Boss。
- 每日种子基于 `YYYYMMDD`，写入 localStorage 的前 10 名排行榜会显示在 lost 面板。
- 失败后点击「再来一次 ↗」会以当日新种子重开。

## 关卡曲线

- 第 1 关「前线阵地」：训练布局，砖墙形成六条可预判的进攻走廊。敌军以轻型为主，4 辆同时在场，间隔 4.5 秒。不掉道具。
- 第 2 关「交叉火力」：横纵交叉水域切断直线，中央钢墙迫使玩家换线。15 辆混编敌军，最多 5 辆同时在场，移动速度提升 8%，射击间隔缩短 10%。开始掉落道具。
- 第 3 关「钢铁堡垒」：更密的砖墙与钢墙形成窄通道，水域保护中轴。18 辆重型/速射混编敌军，最多 6 辆同时在场，移动速度提升 18%，射击间隔缩短 22%。

每一关开始时玩家重置为 3 条命和 3 秒出生保护；当前关失败重试时恢复到该关开始时的分数。最终胜利后的「再次出击」会从第 1 关开启新战役。

## 结构

```
src/
  main.js                    入口及初始化失败处理
  core/GameManager.js        主循环、模式、生成节奏、生命/胜负、UI 同步
  core/Input.js              键盘、鼠标、触屏、失焦清理
  core/config.js             网格、固定步长、兵种、道具、地图预设、无尽缩放
  world/MapManager.js        26×26 网格、实例化砖/钢、地形、基地、加固
  world/models.js            坦克/Boss/老鹰/6 类道具工厂、共享材质
  entities/Tank.js           Tank 基类、PlayerTank、EnemyTank、Boss/Armor 子类
  entities/Pickup.js         道具飘动、拾取、过期
  systems/CollisionSystem.js Grid/AABB 与连续线段扫掠
  systems/BulletManager.js   子弹生命周期、地形/坦克/子弹碰撞、破钢墙
  systems/Effects.js         Points 粒子、爆炸、残骸与烟雾
  systems/AudioSystem.js     用户交互解锁的 Web Audio 合成音效
  systems/Leaderboard.js     localStorage 排行榜（带回退内存）
  systems/RunUpgradeSystem.js 局内改装抽取、叠加和快照
  style.css                  响应式作战界面
  tests/powerups.test.js     道具、升级、钢墙、缩放、排行榜单元测试
```

模拟使用 1/60 秒固定时间步；每帧累积时间限制为 0.1 秒，最多 6 次 tick，避免切换标签页后的跳跃。更新顺序为输入/坦克 → AI → 子弹/碰撞 → 状态 → VFX → 渲染。高速炮弹使用扫掠 AABB，弹弹碰撞使用相对运动扫掠，无重型物理引擎。

正交相机以约 60° 俯角固定观察全图，单平行光开启 2048² 阴影，加中性环境光。DPR 上限 1.5；重复砖块和钢墙使用 InstancedMesh，其他静态组件按材质合并。重开回收场景对象、几何体、实例缓冲与独立材质。

开发环境暴露 `window.__TANK_GAME__` 以支持规则验证和 `snapshot()` 诊断（包含 `mode`/`wave`/`buffs`/`player.level` 等新增字段）；生产打包通过 Vite 的 DEV 分支移除。浏览器检查脚本的 `CHROME_PATH` 可指向本机 Chromium/Chrome。

音效为本地 Web Audio 合成，无外部素材依赖。技术参考：[Three.js 官方安装文档](https://threejs.org/manual/en/installation.html)。

浏览器回归：分别保持 `npm run dev`（5173）和 `npm run preview`（4173）运行，再执行 `npm run test:browser`。默认使用 macOS Chrome；其他路径使用 `CHROME_PATH=/path/to/chrome npm run test:browser`。验证详情及截图见 [artifacts/final-evidence.md](artifacts/final-evidence.md)。
